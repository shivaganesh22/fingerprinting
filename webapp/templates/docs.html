1. Research Purpose & Regulatory Context

Browser fingerprinting tracks users across the web without persistent cookies or local storage by querying subtle hardware, OS, and browser API configurations. Because it executes invisibly without storing state on client devices, it circumvents standard cookie-clearing defenses and raises significant regulatory challenges under the UK GDPR (Article 4 personal data definition) and the ePrivacy Directive (Article 5(3) requirement for explicit consent before accessing equipment information).

This study establishes an automated, reproducible measurement pipeline to: (1) empirically estimate the prevalence of fingerprinting across popular websites sampled from the Tranco top ranking list; and (2) evaluate the true efficacy of privacy countermeasures (blocklists, Manifest V3 extensions, noise injectors, and hardened browsers) using rigorous paired before/after statistical tests.

2. Crawl Pipeline & Instrumentation Architecture

The crawl engine uses Playwright controlling Chromium with custom instrumentation injected via page.add_init_script() prior to document execution.

  • Deterministic Sampling: Samples up to 5,000 domains from a cryptographically verified Tranco list (List ID: GQ3LK).
  • Dwell Time: Waits for a configurable dwell duration (default: 5.0–12.0s) post DOM load to allow asynchronous tracking scripts to execute and complete their canvas/WebGL rendering loops.
  • Event Batching: Raw events (API name, method, truncated arguments, return values, stack trace excerpts, script URL) are batched and buffered via a high-performance ring buffer.
  • Persistence: Results are written in SQLite WAL mode (data/raw/fpstudy.sqlite) ensuring data durability and cross-process thread safety.

3. Observed API Signals & Vector Heuristics

To prevent false positives from benign application code (e.g. video games, charts, WebGL graphics), the detector enforces strict, multi-step rule-based heuristics:

Canvas 2D Fingerprinting: Flagged only when a script renders text using complex fonts/colors or emojis and extracts the rendered image pixels using toDataURL() or getImageData() with at least 2 distinct drawing operations. Simple canvas clears or image resizing are ignored.
WebGL Context Probing: Flagged when querying the unmasked GPU hardware strings (WEBGL_debug_renderer_info parameters UNMASKED_VENDOR_WEBGL and UNMASKED_RENDERER_WEBGL) or sweeping shader precision parameters without rendering visible game geometry.
AudioContext Dynamics: Flagged when creating an OfflineAudioContext or OscillatorNode to process a synthetic frequency signal through a DynamicsCompressor and extracting the resulting frequency buffer to construct an audio fingerprint.
Font Enumeration Probing: Flagged when client-side JavaScript measures the rendered bounding box width or height (offsetWidth / getBoundingClientRect) across >25 distinct installed font family names to detect system-installed fonts.

4. Evaluated Privacy Countermeasures

The study implements five distinct condition architectures, verified via automated canary self-checks before each crawl:

  • Baseline (Vanilla Chromium): Unmodified browser context with standard user agent and hooks.
  • Blocklist (EasyPrivacy): Network-level request interceptor using a fast Rust adblock regex engine that matches outbound script and tracker requests against the canonical EasyPrivacy rule list.
  • uBlock Origin Lite (MV3): Chromium launched with persistent user profile loading the genuine unpacked MV3 extension. Relies on Chrome's declarativeNetRequest rulesets.
  • Canvas Defender: Randomizes pixel values extracted by Canvas readback methods with subtle pseudo-random noise, breaking fingerprint repeatability.
  • Brave Shields: Evaluates native browser protections using the official Brave browser binary.

5. Ethical Crawling, Robots.txt & Failure Categories

Crawling strictly obeys the RFC 9309 Robots Exclusion Standard:

  • The crawler identifies itself via fpstudy-research/1.0 with researcher contact token.
  • Robots.txt is retrieved prior to any page navigation. If the origin disallows the crawler or all user agents from /, the domain is logged as skipped_robots and no further HTTP requests or browser navigations are performed.
  • If a Crawl-delay directive is specified, the crawler dynamically respects that delay or our polite minimum of 5.0 seconds (whichever is larger).

Failure Taxonomy

Status Code Category Handling & Retries
ok DOM loaded, dwell completed Classified and counted in statistical denominator.
skipped_robots RFC 9309 Disallowed Skipped politely. Never retried.
timeout Navigation timeout Retried up to max_retries with exponential backoff.
dns_error DNS resolution failure Retried once. Excluded from paired tests if failed.
crash Renderer / Context crash Cleaned up and logged with error stack trace.

6. Statistical Methodology & Metrics

Comparing independent samples would introduce confounders from site availability and network instability. Therefore, this project implements paired before/after analysis:

  • Paired McNemar's Test: Evaluates binary paired outcomes (presence/absence of fingerprinting). Uses an exact two-sided binomial test when discordant pairs (b + c) < 25, and continuity-corrected χ2 when (b + c) ≥ 25.
  • Absolute Risk Reduction (ARR): ARR = (b - c) / N with 95% Wald confidence intervals.
  • Odds Ratio (OR): OR = b / c, representing the odds of mitigating an existing fingerprint relative to introducing an anomalous signal.
  • Wilcoxon Signed-Rank Test: Non-parametric paired test on the count of flagged scripts per domain, computing rank-biserial correlation r and Hodges-Lehmann median difference.
  • Holm-Bonferroni Correction: Controls Family-Wise Error Rate (FWER) across multi-vector hypothesis testing.

7. Developer & Researcher Replication Guide

Both the web interface and the CLI crawler share identical underlying detection and storage engines.

Web Application:

# Run Django migrations and start development server
python manage.py migrate
python manage.py runserver 0.0.0.0:8000

Command-Line CLI (fpstudy):

# Verify all condition canaries
fpstudy selfcheck

# Sample top 100 domains from Tranco
fpstudy sample --top-n 100

# Execute crawl under baseline condition
fpstudy crawl --condition baseline --limit 100

# Execute crawl under blocklist condition
fpstudy crawl --condition blocklist --limit 100

# Classify stored events and generate report
fpstudy classify --run-id <run_id>
fpstudy report --baseline <base_id> --treatment <treat_id>

8. Threats to Validity & Study Limitations

  • Synthetic Dwell Time: Dwell times of 5–12s may fail to observe scripts that only fire upon active user interaction (scrolling, clicking, mouse movements).
  • Headless Mode Discrepancies: Certain commercial bot-detection scripts detect headless Chromium and modify their tracking behavior accordingly.
  • Extension MV3 Constraints: Manifest V3 declarativeNetRequest operates at the browser level and does not permit dynamic script rewriting in the same manner as legacy MV2 extensions.
  • Geographic & ISP Bias: Crawls originate from a single IP subnet and geolocation (UK/EU), which may trigger localized consent banners or regional tracker behavior.
